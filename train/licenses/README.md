# Third-party attribution

The included LLaMA-Factory source is selected from the project's locally modified
LLaMA-Factory checkout. Its original license text is retained in
`LLaMA-Factory-Apache-2.0.txt`, and its citation metadata is retained in
`LLaMA-Factory-CITATION.cff`. Existing copyright, license, and source-attribution
headers in copied files have been preserved. The public package checksums identify
the distributed source files.

PyTorch, Hugging Face Transformers and the other listed libraries are external
dependencies, rather than vendored library distributions. Their own licenses
apply to those dependencies. No model weights or datasets are redistributed in
this training directory. The repository license applies to project-specific
additions; the retained Apache-2.0 notices apply to the included upstream source.
